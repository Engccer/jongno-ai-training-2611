1회기(11월 11일) 전까지

1. Claude 계정 로그인

Claude Pro 계정으로 로그인합니다. 무료 플랜에서는 실습에 쓸 Code 탭과 Claude Code가 열리지 않으므로 플랜을 먼저 확인해 주세요.

2. Claude Desktop 앱 설치

아래 주소에서 Windows용 앱을 내려받아 설치합니다.

https://claude.ai/download

확인: 앱을 실행해 좌측 사이드바에 코드 항목이 있는지 봅니다. 코드 항목이 보이면 1번과 2번이 함께 확인된 것입니다.

3. Git 설치

Code 탭을 처음 열면 Git 설치 안내 대화상자가 자동으로 뜹니다. 대화상자 안의 Git 다운로드 버튼을 누르고, 내려받은 설치 파일을 실행해 모든 화면에서 기본 설정 그대로 Next 또는 Install을 눌러 끝까지 설치합니다.

「나중에」 버튼을 누르지 마세요. Git 없이 진행되어 다음 단계가 막힙니다.

설치가 끝나면 앱을 완전히 종료한 뒤 다시 실행합니다. Claude 앱은 창을 닫아도 백그라운드에 남으므로 작업 관리자로 끕니다.

  1. Ctrl+Shift+Esc로 작업 관리자를 엽니다.
  2. 가상 커서를 해제하고 목록을 내려가 Claude를 찾습니다.
  3. 팝업 키를 누르고 Alt+E를 눌러 작업을 끝냅니다.
  4. Windows 키를 눌러 검색창에 「클로드」를 입력하고 다시 실행합니다.

작업 관리자 조작이 번거로우면 컴퓨터를 껐다 켜도 됩니다.

확인: 다시 실행한 뒤 Code 탭으로 돌아와 하단 입력창에 아래 문장을 그대로 붙여넣고 보냅니다.

Git 설치를 마쳤는데 제대로 설치된 것인지 확인해 줘.

Claude가 확인을 위해 PowerShell 명령을 실행하겠다며 권한을 묻습니다. 항상 허용을 누르세요. 설치가 확인됐다는 답이 오면 된 것입니다.

환경 변수를 설정해야 한다는 안내가 나오면 시스템 설정 창을 직접 건드리지 마시고 입력창에 아래 한 줄을 보내세요.

PowerShell로 환경 변수를 영구 설정하는 방법으로 네가 바로 해 줘.

환경 변수 설정이 끝나면 위와 같은 방법으로 앱을 한 번 더 종료하고 다시 실행합니다.

4. Node.js와 Python 설치

스킬 설치와 문서 변환에 필요합니다. 3번까지 마치셨으면 입력창에 아래를 그대로 붙여넣으세요.

이 컴퓨터에 Node.js와 Python이 설치돼 있는지 확인하고, 없으면 설치해 줘. 설치가 끝나면 각각의 버전을 알려 줘.

도중에 권한 요청이 뜨면 내용을 읽고 허용합니다. 마지막에 두 프로그램의 버전이 나오면 설치된 것입니다.

5. 홈 디렉터리에 연습 폴더 만들기

홈 디렉터리에 폴더를 하나 만들고 이름을 「연습」으로 붙입니다. Windows에서 홈 디렉터리는 C:\Users\<본인 계정 이름>이며, 파일 탐색기에는 「사용자」 폴더 아래 본인 계정 이름으로 표시됩니다. 파일 탐색기에서 Alt+D로 주소창에 이동해 %USERPROFILE%을 입력하고 Enter를 누르면 바로 열립니다.

연습 폴더 안에는 다음 두 파일을 넣어 주세요.

  • 업무에서 받은 PDF 문서 한 개(공문, 안내문, 보고서 등)
  • 업무에서 다루는 한글 문서 한 개(한글 문서가 없으면 워드 문서)

이름·연락처·주민등록번호 같은 개인정보가 들어 있지 않은 문서로 골라 주세요.

1회기에 Claude에서 이 폴더를 처음 고르면 폴더를 신뢰할지 묻는 화면이 뜹니다. 신뢰 버튼을 누르셔야 그 폴더의 파일을 읽습니다.

3회기(11월 16일) 전까지

7. 업무 폴더 하나 정하기

3회기부터는 연습 폴더가 아니라 본인 업무 자료가 있는 폴더에서 실습합니다. 그 폴더 하나를 정해 주세요.

  • 업무 자료를 모아 두는 폴더면 가장 좋습니다. 정리가 안 돼 있어도 괜찮습니다.
  • USB 안의 폴더는 피해 주세요. 뽑으면 경로가 사라지고 드라이브 문자도 바뀝니다. C 드라이브로 옮겨 두고 쓰시는 편이 낫습니다.
  • 회사 컴퓨터에만 자료가 있으시면 실습에 쓸 컴퓨터의 문서 폴더 아래에 폴더를 하나 만들고, 개인정보가 없는 자료만 옮겨 주세요.

확인: 그 폴더의 경로를 적어 두시면 됩니다. 파일 탐색기에서 그 폴더에 포커스를 두고 Ctrl+Shift+C를 누르면 경로가 복사됩니다.

챗봇에서 에이전트로

챗봇과 에이전트는 사용자의 지시를 처리하는 방식이 다름.

  • 챗봇: 대화창에서 질문에 답하고 초안을 작성함. 보고서 요약을 답변으로 받았다면 사용자가 그 내용을 업무 문서에 옮겨야 함.
  • 에이전트: 지정된 폴더에 직접 들어가 파일을 읽고, 문서를 편집하고, 결과 파일(.hwpx, .docx, .md, .csv 등)을 폴더에 저장함. 탐색기를 열어 보면 파일이 실제로 생성되어 있음.

이 차이가 사무 업무에서 중요한 이유:

  • 사무 업무는 화면 위의 대화로 끝나지 않음.
  • 받은 문서를 열어 검토하고, 서식을 채워 보고하고, 결과 파일을 정리해 보내야 비로소 끝남.
  • 에이전트에게는 초안 작성에 이어 실제 파일 작업까지 맡길 수 있음.

두 도구를 함께 쓰는 이유

Claude Desktop 앱(Code 탭)과 Claude Code CLI(터미널)는 같은 에이전트를 서로 다른 화면에서 쓰는 도구임. 이 과정은 터미널을 기본으로 씀. Desktop 앱은 Git과 CLI를 설치하는 첫 셋업에 씀.

  • 터미널을 기본으로 쓰는 이유: 화면 구성이 입력창과 응답 텍스트뿐이라 스크린 리더 조작 체계가 단순함. 파일 탐색기에서 작업할 폴더로 이동해 바로 실행할 수 있음.
  • Desktop 앱을 먼저 쓰는 이유: 터미널 셋업에 필요한 프로그램 설치를 자연어 지시로 맡길 수 있음.

'Code'라는 이름 때문에 프로그래밍 전용 도구로 생각하기 쉽지만, 문서 작성, 파일 변환, 웹 검색, 시스템 설정 변경에도 쓸 수 있음. 코딩 지식 없이 자연어로 작업을 지시함.

채팅, 코워크, 코드

Desktop 앱에는 세 가지 작업 방식이 있음.

  • 코드: 지정한 로컬 폴더의 파일을 직접 읽고 쓰고, 프로그램을 설치하고, 명령을 실행함.
  • 코워크: 접근을 허용한 파일을 활용해 문서 작성과 정리 같은 업무를 처리함.
  • 채팅: 질문에 답하거나, 올린 자료를 바탕으로 내용을 분석하고 작성함.

프로그램 설치와 명령 실행을 포함한 업무 자동화에는 코드를 씀. Code 탭과 CLI의 로컬 설정·스킬은 채팅·코워크의 설정·스킬과 구분해서 관리해야 함.

Desktop 앱 화면 구조

좌측 사이드바를 위에서 아래로 훑으면 검색, 모드, 채팅 및 코워크, 코드, 새로 생성, 아티팩트, 사용자 지정, 더 많은 탐색 순으로 낭독됨. 메뉴 구성은 자주 바뀜. 이름이 다르게 읽히면 사이드바 전체를 한 번 훑어 확인함.

  1. 코드로 이동하기: 사이드바에서 코드를 고르고 Enter를 누름. 라벨이 「코드 현재 페이지」로 바뀌면 진입한 것임.
  2. 프롬프트 편집창으로 이동하기: F2를 누름.

프롬프트 편집창 주변 항목:

  • 위쪽: 다른 폴더 추가, 로컬 폴더.
  • 아래쪽: 작업을 설명하세요, 보내기, 편집 수락(권한 설정), 추가, 음성 입력, 모델, 노력, 컨텍스트 비율, 빠른 모드.

따라 하기 1: Desktop 앱 Code 탭 셋업

  1. Code 탭으로 이동하기: Claude Desktop 앱을 실행하고, 사이드바에서 코드를 누름.

  2. Git 설치 안내 확인하기: 처음 진입하면 Git 설치 안내가 뜸. Git 다운로드 버튼을 누름.

    • 나중에를 선택하면 Git 연동이 되지 않아 다음 단계가 막힘. 반드시 Git 다운로드를 선택함.
    • 아무 안내도 뜨지 않으면 먼저 폴더를 선택함(따라 하기 2의 1~3번). 폴더를 고른 뒤에 안내가 뜨는 경우가 있음.

    • 다른 에이전트(Codex 등)로 Git을 이미 설치했더라도 안내가 다시 뜰 수 있음. 그 에이전트를 켜 두었다면 해당 에이전트의 입력창에 다음을 보냄.

      Claude를 쓰려는데 Git을 설치하라고 나와. Git이 전역으로 설치되어 있는지 확인해 줘.

  3. Git 설치하기: 내려받은 설치 파일(Git-x.x.x-64-bit.exe)을 실행하고, 설치 마법사의 모든 화면에서 기본 설정 그대로 Next 또는 Install을 눌러 설치를 마침.

    • Git 설치 안내에서 진행되지 않는 경우: 다운로드 페이지 열기를 누름. 브라우저 창이 열리지 않으면 파일 탐색기에서 다운로드 폴더를 열어 설치 파일이 있는지 확인함. 내려받은 exe 파일이 있으면 실행함.
    • Git 설치를 마치기 전에는 프롬프트 입력창이 비활성이라 메시지를 보낼 수 없음. 입력창이 잠겨 있어도 정상임.
  4. 앱 완전 종료 후 다시 실행하기: Git 설치가 끝나면 앱을 완전히 닫고 다시 실행해야 함. 종료 방법은 「조작이 먹히지 않을 때」의 「앱 완전 종료 방법」 참조.

  5. 설치 확인 요청하기: Code 탭으로 돌아와 하단 프롬프트 입력창에 다음을 보냄.

    Git 설치를 마쳤는데 제대로 설치된 것인지 확인해 줘.

  6. PowerShell 실행 권한 허용하기: Claude가 설치 상태를 확인하려고 PowerShell 명령 실행 권한을 요청하면 명령 내용을 확인함. 거부, 한 번만 허용, 항상 허용 중 항상 허용을 선택하면 해당 허용 규칙에 맞는 명령에는 다시 묻지 않음.

  7. 필요한 경우 환경 변수 설정하기: Git이 설치되어 있어도 Claude가 bash.exe 경로를 찾지 못하면 CLAUDE_CODE_GIT_BASH_PATH 환경 변수 설정 안내가 뜸. PowerShell로 설정하는 방법과 Windows 설정 창에서 직접 넣는 방법을 함께 제시하면 Code 탭 입력창에 다음을 보냄.

    PowerShell로 환경 변수를 영구 설정하는 방법으로 네가 바로 해 줘.

    Claude가 PowerShell 명령으로 환경 변수를 설정함. 안내에 붙은 번호는 그때그때 다르므로 번호 대신 방법을 말함.

    • 환경 변수 안내가 뜨지 않고 Git을 정상적으로 인식하면 추가 설정 없이 진행함.
    • 「현재 세션의 PATH에는 아직 반영되지 않았다」는 안내가 나오면 앱을 완전히 종료하고 다시 실행한 뒤 설치 상태를 다시 확인함.

확인 방법: 5번 지시에 Git이 설치됐다는 답이 돌아오면 이 단계를 마친 것임.

앱을 최신으로 유지하기

Desktop 앱은 자주 업데이트됨. 구버전에서는 메뉴가 다르게 보이거나 권한 설정이 나타나지 않을 수 있음. 처음 설치했다면 업데이트를 몇 번 반복해야 정상 화면이 나오기도 함.

  • 앱 안에서 검색으로 「업데이트」를 찾아 실행함.

조작이 먹히지 않을 때

엉뚱한 라벨이 읽히거나, 가상 커서를 해제해도 방향키가 듣지 않는 경우가 있음. 아래 순서로 복구함.

  1. Esc를 여러 번 눌러 열려 있는 목록 닫기
  2. F2로 프롬프트 편집창으로 돌아가기
  3. F5로 화면을 새로 읽고 다시 탐색하기
  4. 그래도 라벨이 어긋나면 앱을 완전히 종료하고 다시 실행하기

앱 완전 종료 방법

Alt+F4로 Claude Desktop 앱 창을 닫아도 백그라운드에 남을 수 있음. 완전히 종료하려면 작업 관리자에서 끝냄.

  1. Ctrl+Shift+Esc로 작업 관리자 열기
  2. 가상 커서를 해제하고 목록에서 Claude 찾기
  3. 팝업 키를 누르고 Alt+E(작업 끝내기) 누르기
  4. Windows 키를 눌러 검색창에 「클로드」를 입력하고 실행하기

컴퓨터를 껐다 켜도 결과는 같음. 설치나 설정을 반영하려고 앱을 다시 켜야 할 때도 이 방법을 씀.

따라 하기 2: 폴더 지정과 첫 지시

에이전트는 지정한 폴더를 작업 범위로 삼음. 폴더를 지정해야 결과 파일이 정확한 위치에 생성됨.

  1. 작업 폴더 선택하기: Code 탭의 프롬프트 편집창에서 위로 올라가 로컬 폴더를 고르고 Enter를 누름. 폴더 선택 대화상자가 열림.
  2. 연습 폴더 지정하기: 홈 디렉터리에 미리 만들어 둔 연습 폴더로 이동한 뒤 폴더 선택 버튼을 누름. 입력창 상단에 폴더 이름이 표시되면 지정 완료.
  3. 폴더 신뢰하기: 처음 여는 폴더면 신뢰를 묻는 화면이 뜸. 본인이 준비한 연습 폴더가 맞는지 확인하고 신뢰 버튼을 누름.

  4. 첫 지시 보내기: Code 탭 하단 입력창에 다음을 입력하고 전송함.

    이 폴더에 어떤 파일이 있는지 읽고 정리해 줘.

  5. 결과 확인하기: 연습 폴더에 넣어 둔 PDF와 한글 문서의 파일 이름·형식이 답변과 일치하는지 확인함.

작업 범위와 권한 관리

  • 작업 범위: 선택한 폴더를 기준으로 파일을 읽고 작업함. 폴더 지정만으로 그 밖의 접근이 모두 차단되는 것은 아님. 실제 접근·실행 권한은 별도 설정으로 관리함.
  • 승인 요청이 뜬 경우: 대상 파일과 실행할 명령을 확인하고 허용 여부를 결정함. 폴더 밖 접근이나 프로그램 설치도 현재 권한 설정에 따라 승인 요청이 뜰 수 있음.
  • 자동 모드: 실행하려는 작업을 자동으로 검토해 승인 요청을 줄이는 설정임. 프롬프트 편집창 아래의 편집 수락 풀다운 메뉴에서 자동을 선택하고, 확인 창에서 자동 모드 활성화를 누름.
  • 수동 승인: 파일 편집이나 명령 실행 때 승인 요청이 뜨면 내용을 확인하고 응답해야 작업이 계속됨.

자동 모드가 보이지 않는 경우: 앱 업데이트 상태와 계정·조직의 설정을 확인해야 함.

워크스페이스

관련 자료와 작업을 묶어 관리하는 상위 폴더를 워크스페이스라고 부름. 실제 작업 범위는 그 폴더 전체나 하위 폴더 중에서 선택할 수 있음.

  • 분류 예시: 회사 업무 폴더, 개인 프로젝트 폴더, 업무용 구글 드라이브, 개인 구글 드라이브.
  • 업무용과 개인용 정도로 큰 갈래를 먼저 나누고, 그 안을 하위 폴더로 정리함.
  • 홈 디렉터리: Windows의 홈 디렉터리는 C:\Users\<본인 계정 이름>임. 사용자별 설정과 전역 스킬을 저장하는 기준 폴더로 쓰임.
  • 구글 드라이브: 데스크톱용 구글 드라이브를 설치했다면 파일 탐색기에서 열 수 있는 드라이브 폴더를 작업 범위로 지정할 수 있음.

파일 경로를 정확히 전달하는 요령

  • 파일 탐색기에서 대상 파일을 선택하고 Ctrl+Shift+C를 누르면 전체 경로가 클립보드에 복사됨. 이를 Claude 입력창에 붙여넣고 작업을 지시함.
  • 폴더에 비슷한 이름의 파일이 여러 개일 때도 작업할 파일을 정확히 지정할 수 있음.

따라 하기 3: 터미널 CLI 환경 셋업

같은 Claude 에이전트를 터미널에서 가볍게 구동하는 절차임.

필요한 프로그램 설치하기

Windows 터미널, PowerShell 7, Claude Code CLI가 설치되어 있어야 함. Claude Desktop 앱 Code 탭 입력창에 다음을 보냄.

이 컴퓨터에 Windows 터미널이 설치돼 있는지 확인하고, PowerShell 7과 Claude Code CLI를 설치해 줘.
  • Windows 터미널이 없는 경우: Microsoft Store에서 설치함.
  • PowerShell 7과 Claude Code CLI: Claude의 답변에서 두 프로그램의 설치 결과를 확인함. CLI는 command line interface, 명령 줄 인터페이스의 약자임.
  • 답이 「진행 중」에서 멈춘 경우: 응답을 다시 훑고 Claude 입력창에 설치가 완료됐는지 물어 결과를 확인함.

터미널과 셸

  • 터미널: 텍스트를 입력하고 프로그램의 출력을 확인하는 앱임. 예: Windows의 Windows 터미널, macOS의 터미널.
  • 셸: 입력한 명령을 해석하고 프로그램을 실행하는 도구임. 예: PowerShell, zsh.

하나의 터미널 앱에서 여러 셸을 골라 실행할 수 있음. PowerShell 프롬프트 앞머리의 PS는 PowerShell의 약자임.

「Windows PowerShell」과 「PowerShell 7」은 별도로 설치되는 프로그램임. Windows PowerShell은 Windows에 기본으로 들어 있는 이전 버전임. PowerShell 7을 설치했어도 터미널의 기본 셸은 Windows PowerShell로 남아 있을 수 있음. 기본 셸을 바꾸려면 Claude Desktop 앱 Code 탭 입력창에 다음을 보냄.

Windows 터미널을 열었을 때 PowerShell 7이 뜨도록 기본 설정을 바꿔 줘.

Claude Code 실행하기

  1. 작업 폴더 열기: 파일 탐색기에서 홈 디렉터리의 연습 폴더로 들어감.
  2. 파일 선택 해제하기: 파일이 선택돼 있으면 Ctrl+Space로 선택을 해제함. 선택된 상태에서는 해당 파일의 메뉴가 열릴 수 있음.
  3. 터미널 열기: 팝업 키(또는 Shift+F10)를 눌러 컨텍스트 메뉴를 열고 터미널에서 열기를 선택함. 메뉴 순서와 단축키는 환경에 따라 달라질 수 있으므로 항목 이름을 확인함.

  4. Claude Code 실행하기: 터미널의 PowerShell 프롬프트에 다음을 입력하고 Enter를 누름.

    claude

  5. 첫 실행 설정하기: 테마 선택 화면이 나오면 원하는 테마를 고름. 화면 색상 설정임.

  6. 구독 계정으로 로그인하기: 구독 로그인과 API 로그인 중 구독 로그인을 고름. 목록의 첫 번째임. 이어서 열린 브라우저에서 Claude 구독 계정으로 인증을 마치고 터미널로 돌아옴.
  7. 폴더 신뢰하기: 이 폴더를 신뢰하는지 묻는 화면이 나오면 연습 폴더가 맞는지 확인하고 신뢰를 고른 뒤 Enter를 누름.
  8. 동작 확인하기: Claude Code 입력창이 나타나면 간단한 지시를 보내 응답이 출력되는지 확인함.

  • claude를 찾을 수 없다고 나오는 경우: 설치 직후라 터미널이 새 경로를 아직 모르는 것임. 터미널을 닫고 3번부터 다시 엶.

  • 탐색 방법: 터미널의 출력 내용은 센스리더 키패드 리뷰로 훑음. 방향키는 입력 편집이나 선택 목록 조작에 쓰임.

  • 화면 언어: 첫 설정과 인증 화면은 영어로 나옴. 이 단계만 넘기면 이후는 한국어로 대화함.
  • 기본 위치: Windows 검색창에서 wt를 입력해 터미널을 열면 홈 디렉터리에서 시작함. 폴더에서 바로 여는 방법과 목적지가 다름.

터미널을 연 바로 그 폴더가 자동으로 작업 범위가 되므로, 앱처럼 폴더를 별도로 지정하지 않음.

  • 셸에서 폴더 이동하기: Claude Code를 실행하기 전 PowerShell 프롬프트에서 cd ~를 입력하면 홈 디렉터리로 이동하고, dir를 입력하면 현재 폴더의 목록을 봄.

따라 하기 4: 스크린 리더 모드 켜기

  • 문제: 터미널 화면에는 테두리 선이나 진행 애니메이션 같은 장식 문자가 포함되어 있어, 키패드로 탐색할 때 불필요한 음성이 많이 낭독됨.
  • 해결: Claude Code가 이를 평문으로 전환해 주는 전용 스크린 리더 모드(axScreenReader)를 기본 제공함.

터미널에서 실행한 Claude Code 입력창에 다음을 보냄.

클로드 코드 설정에서 스크린 리더 모드 켜 줘.
  • 「클로드 코드 설정에서」까지 입력해야 함. 이 말을 빼면 다른 접근성 설정과 혼동해 무엇을 켤지 고르라는 목록이 뜰 수 있음.
  • 고르라는 목록이 떴으면 목록에서 하나를 고르지 말고 위 문장을 그대로 다시 보냄.
  • 전역(Global) 설정으로 저장되므로, 한 번 켜 두면 터미널을 다시 열거나 다른 폴더에서 작업할 때도 유지됨.

확인 방법: 터미널을 닫고 따라 하기 3의 「Claude Code 실행하기」 1~4번대로 연습 폴더에서 다시 열어 claude를 실행함. 시작 화면에 스크린 리더 모드가 켜져 있다는 안내가 나오면 적용된 것임. 키패드로 훑어 장식 문자가 사라졌는지도 함께 봄.

터미널에서 Claude 다루기

터미널은 조작 체계가 단순한 대신 화면을 훑는 방법이 앱과 다름.

입력창은 맨 아래에 있음

  • 채팅창과 같은 구조임. 입력창이 화면 맨 아래고, 그 가까이에 권한 모드 줄이 있음.
  • 커서가 입력창에 있어도 센스리더가 위쪽 내용을 읽고 있을 때가 있음. 입력하기 전에 아래 화살표를 두어 번 누름.
  • 선택 목록이 떠 있을 때는 화살표를 누르지 않음. 화살표가 고른 항목을 바꿈. 목록의 항목은 번호나 문자를 입력한 뒤 Enter로 고름.

키패드로 지난 응답 읽기

  • 위아래 화살표로는 읽히지 않음. Ctrl+넘패드 2로 맨 아래로 간 뒤 위로 올라가며 읽음.
  • 한 줄씩 위아래로만 오가면 되므로 익으면 단순함. 점자 디스플레이를 연결하면 훨씬 빠름.

선택지 입력 후 Enter 누르기

  • 숫자든 y든 n이든 누르고 Enter를 쳐야 넘어감. 스크린 리더 모드에서는 이것이 기본값임.
  • 입력 후 화면이 바뀌지 않으면 Enter를 눌렀는지 확인함.

Shift+Tab으로 권한 모드 바꾸기

  • Shift+Tab을 누를 때마다 권한 모드가 바뀌며, 현재 모드는 입력창 가까이에 표시됨. 기본 모드(default), 편집 자동 승인(acceptEdits), 계획 모드(plan)가 있고, 계정과 설정에 따라 자동 모드(auto) 등이 추가됨.
  • 편집 자동 승인은 파일 편집을 자동으로 허용하는 설정임. 자동 모드는 도구 실행을 검토해 허용 여부를 판단함. 자동 모드에서도 작업이 차단되거나 멈출 수 있으므로 마지막 응답을 확인해야 함.

작업 중 진행 줄의 반복 낭독 줄이기

작업 시간이 갱신되면서 같은 줄이 반복 낭독될 수 있음. 다음 방법 중 하나로 줄임.

  • 지시를 보낸 뒤 다른 창으로 포커스를 옮기고 끝나기를 기다림.
  • 점자 디스플레이를 연결함. 스크린 리더 낭독 개입 없이 내용 확인 가능.
  • 음성만 잠시 끔.

영어로 표시되는 작업 과정 읽기

에이전트의 작업 과정이 영어로 길게 표시될 수 있음. 작업 결과는 요약으로 확인하고, 상세 과정이 필요할 때 키패드로 위쪽 내용을 읽음.

터미널 창과 새 대화 열기

  • Ctrl+Shift+T로 새 탭을 엶. 안 되면 Ctrl+Shift+숫자 1.
  • 둘 다 안 되면 처음처럼 wt로 새 창을 엶. 여러 창을 함께 열 수 있음.
  • 대화를 새로 시작하려면 exit로 나갔다가 claude를 다시 실행함.

  1. 터미널에서 Claude 열기: 따라 하기 3의 「Claude Code 실행하기」 1~4번대로 연습 폴더에서 터미널을 열고 claude를 실행함.

  2. 인터뷰 요청하기: 대괄호를 본인 직무로 바꾼 뒤 Claude Code 입력창에 보냄.

    나는 [직무]로 일하는 시각장애인 재직자야. 내 업무에서 AI 에이전트에게 맡길 만한 일을 찾고 싶어. 질문을 한 번에 하나씩 해서 인터뷰해 줘. 하는 일, 반복 업무, 주로 다루는 파일 형식, 스크린 리더로 다루기 어려운 업무 화면이나 문서, 지금 쓰는 AI 도구를 차례로 물어봐 줘. 인터뷰가 끝나면 내용을 정리해서 이 폴더에 내 업무 정리.md 파일로 저장해 줘.

  3. 질문에 답하기: 질문이 하나씩 나오면 입력창에 답을 적어 보냄. 보기를 고르는 목록으로 물으면 화살표 대신 번호를 입력하고 Enter를 누름.

  4. 파일 확인하기: 파일 탐색기에서 연습 폴더를 열어 내 업무 정리.md가 생겼는지 확인함. 메모장으로 열어 내용을 읽음.

함께 나누기

파일 탐색기를 빠르게 쓰기

파일 탐색기는 Windows 키+E로 엶. Windows에서 파일 시스템을 여는 앱이며 macOS의 Finder에 해당함.

  • 즐겨찾기 패널: 파일 목록에서 Shift+Tab을 누르면 최근에 작업한 폴더가 모인 패널로 이동함. 숫자 키로도 고름.
  • 자주 가는 폴더 고정: 폴더에서 팝업 키를 눌러 즐겨찾기에 고정을 선택함. 단축키는 Alt+Q. 업무 폴더, 개인 폴더처럼 매일 여는 곳을 고정해 두면 Shift+Tab 한 번으로 오감.
  • 탭으로 관리: Ctrl+T로 새 탭을 열고 Ctrl+F4로 닫음. 메모장도 같은 단축키를 씀. 창을 여러 개 띄우지 않으므로 Alt+Tab으로 오가야 할 대상이 줄어듦.
  • 가상 데스크톱: Ctrl+Windows 키+D로 추가하고 Ctrl+Windows 키+좌우 방향키로 전환함. 브라우저와 메신저를 한쪽에, 파일 탐색기와 터미널을 다른 쪽에 두면 창이 섞이지 않음.
